# Recaudación 365 Enterprise V15 (Visión)

Esta versión propone la siguiente evolución sobre V14:

- Dashboard ejecutivo tipo Power BI.
- Portal unificado de aplicaciones.
- IA/Copilot con análisis automáticos.
- Reporte PDF ejecutivo.
- Histórico por meses y años.
- Centro de notificaciones.
- Perfil de usuario ampliado.
- Diseño móvil optimizado.
- Base preparada para integrar todos los módulos (AVA, Happy Moments,
  Semáforo, Factor, Adeudos y Chatbot).

Esta entrega mantiene la base funcional de la V14 y añade la hoja de ruta
y estructura para la siguiente fase de desarrollo.
